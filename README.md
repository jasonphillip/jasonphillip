# Jason Phillip

Applied AI engineer, founder of [Tychon AI](https://tychonai.com). I direct coding agents to build software for space and quantum-sensing hardware, and I check what they produce.

**[tychon-quantum-sensing](https://github.com/jasonphillip/tychon-quantum-sensing)** is the one to read. It holds a physics simulator, an INT8 edge model, and PID plus neural-network control on a PolarFire SoC FPGA, built with orchestrated agents and checked by local LLM critics. Start with the [three engineering decisions](https://github.com/jasonphillip/tychon-quantum-sensing/blob/main/docs/engineering-decisions.md) on a retracted benchmark, a watchdog fix tested on the board, and an objective removed after a three-seed ablation.

Earlier work includes a star tracker and a spectrum-monitor classifier sized for an FPGA.
